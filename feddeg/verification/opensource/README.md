# Независимая проверка ДЭГ

Реализация криптографических проверок с нуля на Python. Из внешних зависимостей требуются только Python ≥3.10,
`libgcrypt20` (для Стрибога), `tqdm` (для прогресс-бара).

```bash
python3 verify.py dumpfile.{zip,json}
```

В обычном режиме проверяются GOST- и TeZhu-подписи, форма и ZKP бюллетеней, агрегация ключей и шифротекстов, два Chaum–Pedersen-доказательства расшифровки и соответствие результатам.

Также есть флаг `--results-only`, при котором пропускаются все проверки подписей и бюллетеней (они занимают >99% времени), кроме аггрегации суммы голосов, и `--workers N` для обработки в `N` потоков.

Коды выхода: `0` — проверка успешна, `1` — ошибка/нарушение, `2` — неполная проверка. В `--results-only` код `0` означает успешную проверку только итогов.

Текущая реализация на чистом Python значительно медленнее CSP и на ЕДГ-2026 её выполнение должно занять порядка сотни CPU-часов (в режиме `--results-only` порядка двух часов, упирающихся в пропускную способность диска и у меня после ~3 ядер не ускоряющихся паралеллизмом). Её планируется соптимизировать через Cython. Также каждому потоку может потребоваться до 1гб оперативной памяти на не очень оптимальную дедупликацию избирателей.
